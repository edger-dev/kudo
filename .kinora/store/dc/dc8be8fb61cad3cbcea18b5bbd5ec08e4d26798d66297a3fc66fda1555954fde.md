# wasm-opt aborts on the console's release build

`dx build -p kudo-console --web --fullstack --release` runs binaryen's
`wasm-opt` (version 126, from the dev shell) and it dies with SIGABRT, no
output. dx goes on with the unoptimized release wasm (about 2.4 MB), so the
console works; it is only bigger than it needs to be. Likely a wasm feature
mismatch between rustc's output and this binaryen; try a newer binaryen, or
dx's `wasm-opt` settings in Dioxus.toml.
