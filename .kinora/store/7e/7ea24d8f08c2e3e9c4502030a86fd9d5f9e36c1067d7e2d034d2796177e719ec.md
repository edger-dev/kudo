# Spec — every component is an engine, a transport, a face, or an environment

**Contract.** Each component has exactly one **kind**, and the kind fixes what it
may hold and what it may link:

| kind | holds | links | today |
|---|---|---|---|
| **engine** | the capability itself — state, policy, lifecycle | **no** transport, **no** UI framework, **no** protocol SDK | `moco`, `kinora`, `kura` |
| **transport** | routing, reachability, topology | no domain semantics | `hub` |
| **face** | a thin per-consumer adapter — an MCP shim, a console, a CLI | the engine it presents | `kudo` |
| **environment** | a host in which faces run, driven by data rather than by hand-built UI | the faces it hosts | `tsui` |

**An engine linking no transport and no consumer protocol is the load-bearing
clause.** It is what allows an engine to be re-hosted without change: the kara
supervisor was designed standalone — own daemon, own socket, own UI, own shim —
and folding it onto an existing daemon **deleted more code than it added**, with
its core untouched, precisely because the core linked none of them.

**Chosen.** A small closed set of kinds, assigned per component. Kind answers the
question layering leaves open: *given several legal placements, which one is
right?*

**Rejected.** Kind as a per-module judgement rather than a per-component one — it
reintroduces the case-by-case reasoning this exists to remove, and the second
module always argues for an exception. Also rejected: collapsing **environment**
into **face**; an environment hosts faces and gives the user control over how data
is seen, which is a different job from adapting one engine to one consumer.

**Escape hatch.** A component that genuinely spans two kinds is two components.
Splitting is cheap; a component with two jobs is what produces the upward edge
that kino://d51a6329ddfc69986e2fa7ee5835e51d30c8c62c324d47e3d5c85a43ffa29801 forbids.

**Corollary — host a capability on the daemon that already exists.** A second
per-node daemon duplicates transport, liveness, and deployment for no capability.
If you are writing one, ask what the first is missing.
