# The console starts workers only on the nodes it is told of

**Chosen.** `KUDO_CONSOLE_WORKER_NODES` (comma-separated node ids) names the
nodes the console may start a worker pane on. When it is set, the console
offers "start a worker" only on those nodes and refuses a start on any other.
Unset, every node the hub reaches is offered (local development).

**Why.** Which machines may run unattended workers is the operator's call — for
now only yolo, sandboxed behind OneCLI. The check sits on the server, so a page
cannot ask past it.

**Rejected.** Hard-coding a node name; an allowlist on the node (the node-side
decision is what its workers may do — see the bypass spec — not who may start
them).

**Escape hatch.** Set the variable to the nodes wanted, or unset it.
