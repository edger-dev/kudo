# Finding, 20 Oct 2026: jig's crane source filter breaks `nix build .#kudo`

jig's rust jig builds from `craneLib.cleanCargoSource`, which keeps only Rust
sources. kudo-node's tests `include_str!` files under `docs/` and
`packaging/`, so the sandboxed `cargo test` in `nix build .#kudo` (and the
`build` check) fails to compile. Broken since the docs test landed (6a08ef4).

Worked around in kudo: `homeModules.kudo-node` defaults to the package with
`doCheck = false`; the tests run under `cargo test`.

Fix belongs in jig: a `rust.extraSrc` (paths or a filter) merged into the
crane source, so a workspace can keep the non-Rust files its tests read.
