# Spec — a governed job a worker starts is traced in its context

**Contract.** A job a worker starts on any node carries the worker's lease as
a tag. When the worker sees the job end (through waiting on it or tailing it),
it appends a **job** event to its lease's trace: the node, the argv that ran,
the verdict that let it run (rule, once, always) or refused it, and the exit.
The node's audit file stays the authority; the trace line is the context's
pointer to it.

**Chosen.** The worker is the one writer that knows the context, and it
already writes the trace; the context reads why a command ran next to what
the worker concluded from it.

**Rejected.** The node publishing each audit record for the console to write
into the tagged context: it works after the worker is gone, but trace writes
would need the console running.

**Escape hatch.** A job whose worker ended before it did is found by its tag in
the node's audit; publishing audit records as hub events stays possible later
without changing the trace event.
