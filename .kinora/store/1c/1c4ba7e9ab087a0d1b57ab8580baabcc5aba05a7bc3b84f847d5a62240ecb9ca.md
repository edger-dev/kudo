# Finding, 20 Oct 2026: rmcp's tools/list was rejected by the agent CLI

The agent CLI (2.1.289) negotiates MCP 2026-07-28 when the server accepts it,
then requires `ttlMs` and `cacheScope` on `tools/list`. rmcp 3.0.0-beta.2 knows
the version, so it accepts it, but the `#[tool_handler]` macro builds the reply
without those fields; the CLI drops every tool from the server. The handler
cannot decline the version: rmcp negotiates again after `initialize`.

Fixed in kudo-shim by writing `list_tools` by hand (ttl 0, private scope). Every
kudo tool, the job tools included, was invisible to the CLI until then. Worth
an upstream report, and a check when rmcp is bumped.
