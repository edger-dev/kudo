# Spec — the console's selection lives in the URL

**Contract.** What is selected — the view (contexts or a node), the context,
the context tab (head or trace), the node, the job or pane — is written to
the URL fragment as it changes, and read from it when the page loads. A
deeper selection pushes a history entry, so the browser's (and the phone's)
back walks out one level; a sibling change replaces the entry. An unknown or
stale fragment selects nothing rather than failing. No secret and no input
text is ever written there.

**Chosen.** The fragment, written by the page; links can be shared between
the author's own devices and survive a reload.

**Rejected.** A router with server-side paths (every path must then be
served; the fragment never reaches the server); keeping state only in memory
(a reload or a lost tab loses the place).

**Escape hatch.** Per-viewer conveniences that are not a place (theme, pane
widths) stay in browser storage, not the URL.
