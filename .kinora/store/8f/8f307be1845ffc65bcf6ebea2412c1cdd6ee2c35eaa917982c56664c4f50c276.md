# Decision, 23 Oct 2026: governed jobs on a second host — the four gaps

From kino://ab39d35e5a302333c60baa345c55f92821806d7f4334e5cc4cc3de03f93457cc. Decided by the author; the specs live in moco's
ledger (commit `7dd288c`), cited there by id.

1. **Node recipes.** A `recipes` call lists the manual entries of the node's
   own manifest; a named start may ask for a node recipe and still passes the
   gate. moco spec `node-recipes-by-name`, id
   `7735b6fcb04483f5bb958b825bd6e7057146db208d5f5e5b9da25d4ad9dcff01`.
2. **A job's exit survives its node restarting.** A wrapper writes the exit
   code beside the output; re-adoption reads it, or says "the node restarted
   under this job". moco spec `job-durability-both-kill-vectors` v2 (version
   `d7ba7c887089648434bc819ad57473bb930242c27396d150b11617388bb85da0`).
3. **An ad-hoc start without a cwd runs in the node's allowed root** (the
   caller's directory only on its own node). moco spec
   `adhoc-cwd-defaults-to-node-root`, id
   `213c9b96650e507051c35dd2d9f71d5d8ba6bb3e8c4ec72b2a9e1b6b7f460104`.
4. **Stable argvs:** covered by 1; no change of its own.
