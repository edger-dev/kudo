# kudo-shim answers --version and --help without starting a server

**Chosen.** `kudo-shim --version` (or `-V`, `version`) prints `kudo-shim
<version>` and exits 0; `kudo-shim --help` (or `-h`, `help`) prints its usage —
the MCP server, `hook`, `context`, `worker` — and exits 0. Neither reads stdin
or dials anything.

**Why.** Run with no arguments the binary is an MCP stdio server, so any flag
it did not know started a server that failed on a closed stdin — a worker asked
for its version and had to read a nix store path instead.

**Rejected.** A full argument parser: the binary's other faces are few and
already dispatched by their first word.

**Escape hatch.** None needed; unknown arguments behave as before.
