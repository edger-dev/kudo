# Spec — a worker pulls its work; a session is a lease, not the unit

**Contract.** An agent session attached to kudo is a **worker**. It does not
receive turns; it **pulls**: it asks kudo for the next unit of work under the
context it is bound to, performs it, and **submits** what it established. Then
it pulls again. What a human types into kudo is an item **enqueued under a
context**, never a message sent into a session.

A session is therefore a **lease** on a context: one session may work several
items, and one item may outlive the session that started it. Nothing a later
worker needs may live only in a session's transcript; it is in the submission,
or it is lost by design.

The pull loop is driven through the agent CLI's own extension surface (its
hooks and tool protocol), never by injecting keystrokes into a terminal and
never by a private harness around the CLI. The worker runs as the ordinary
interactive CLI in a terminal pane a human can sit down at.

**Chosen.** Pull, with the session demoted to a lease. This is the shape that
already worked for case memory in the notes vault — the case outlived many
sessions and a session could touch many cases, once the resume state lived with
the case rather than the transcript — and the shape that worked for the staged
orchestrator prototype, where stages were claimed by whoever pulled them. Both
proved the same thing: when the unit of memory is the work and not the session,
a session can be thrown away.

**Rejected.** Driving the session by pushing turns into it (a pipe or
keystrokes). It keeps the session as the unit — the thing with the history, the
thing you must not lose — which is the failure mode being removed. Also
rejected: a bespoke harness that owns the agent process; the agent CLI is the
product, the worker is a way of using it, and the loop must survive the CLI
changing underneath.

**Escape hatch.** A headless pipe adapter (prompt in, structured events out)
behind the same worker interface, for unattended runs where no pane exists. It
is an adapter, not the seam.
