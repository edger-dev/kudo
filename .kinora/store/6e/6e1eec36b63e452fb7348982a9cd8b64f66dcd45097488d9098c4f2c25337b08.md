# Finding, 20 Oct 2026: two hosts need hub federation, which does not exist

The target topology is one hub per incus host (pc, edger); each host's nodes
(the host itself and its yolo container) dial their own host's hub, and only
the hubs talk across hosts. The hub has no hub-to-hub link today: a node dials
exactly one hub, and a consumer attached to one hub sees only that hub's
nodes.

Phase 0 therefore runs on one host. Before kudo needs a worker on the other
host (the tracer bullet's "two nodes" across machines, or the dogfood week),
the hub needs a federation spec and task in its own ledger: how two hubs
exchange registry and routing, and what a consumer sees.
