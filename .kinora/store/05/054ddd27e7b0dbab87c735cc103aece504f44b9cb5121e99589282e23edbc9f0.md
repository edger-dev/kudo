# Task — the agent face: a stdio MCP shim over the job substrate

Build the agent-facing half of the process manager in **kudo**: a stdio MCP
server, launched per session, that proxies the job substrate running on any node
in the mesh. This is the umbrella tracking item.

**Plan:** kino://62a9e810c2be2563e9f47b63b3fd14535fd00240636f8ba2de8c168821354327
— v1 takes the shim as far as the far side allows: it becomes a real hub consumer
(`nodes` from topology, then routed calls proven against hub's reference files
connector), and stops at the job tools, which have no connector to reach yet.

## Done-when

- A stdio MCP server runs as a session child and needs **no configuration** to
  know its workspace: cwd is the answer.
- It holds no state; every tool call is a routed call to an engine, and two
  readers always see the same world.
- One shim reaches every node: the node (and optional link) is a per-request
  argument, and a solo single-link setup passes neither.
- Its tool surface is the engine's Func surface minus `decide`; nothing on it
  can grant authority.
- A foreign-workspace write is refused with the engine's own error, unwidened.
- Each realizing module cites its spec, using the id form for anything owned by
  another component.

## Known-open, to settle before or during the plan

- **This is kudo's first crate.** The workspace here is `members = []` with no
  `crates/` directory; the layout and the `[workspace.lints]` wiring land with it.
- **The engine surface is only partly built.** moco today has
  `start`/`tail`/`wait`/`kill`/`preflight`/`run` plus an in-memory `list`; the
  supervision verbs the brief's tool surface assumes — `stop`, `restart`,
  `ensure`, `adopt`, `clear`, `screen`, `snapshot`, `stats` — arrive with the
  companion task. Ship against what exists and grow; do not stub the rest here,
  since a face that fakes a capability is a face holding engine logic.
- ~~**A Rust dependency on `hub-protocol` crosses a repo boundary for the first
  time.**~~ **Settled:** a git dependency pinned to an explicit revision, with an
  uncommitted `[patch]` override for local iteration —
  kino://8b09e3e9bdc7712b5e53412964fd2d4668e095e2a13e3d2b74c77e1bac3c11de.

- **Components exchange bytes, never typed values.** `moco`, `kinora` and `hub`
  are on `facet` 0.43.2 / 0.46.0 / 0.50.0-rc.5 respectively, so this shim — the
  first thing to depend on more than one component — will carry two versions of
  `facet` in one build graph. That is safe **only** because a `RoutedCall`
  payload is opaque bytes
  (`hub:d78fb95fddc31aa42bc927da1eaed44292529b3671d1ef9ef58ec8cd0858e51c`). Do not
  reach for a shared `Facet`-derived type across a component boundary; encode to
  bytes on each side. Converging the versions is separate, deferred work.
