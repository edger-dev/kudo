# Spec — the console's theme follows the system unless the viewer picks one

**Contract.** The console has a light and a dark theme, drawn from one set of
colour tokens. By default it follows the system preference; a toggle cycles
system → dark → light → system, applies at once, and is remembered in that
browser only (a missing or refused storage just means "system"). States read
the same in both themes: green running / allowed / exit 0, amber pending /
starting, red failed / denied / unreachable, grey stopped.

**Chosen.** Three states with a way back to "system", per viewer.

**Rejected.** Light only (unreadable at night on a phone); a two-state toggle
(no way back to following the system).

**Escape hatch.** More themes are more token sets; no component names a
colour.
