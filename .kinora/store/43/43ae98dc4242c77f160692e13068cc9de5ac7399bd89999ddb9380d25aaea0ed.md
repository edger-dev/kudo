# Spec — workers inherit the context mirror's dedicated proxy

**Contract.** `KINORA_MIRROR_PROXY` is optional non-secret context-mirror
configuration. A worker launcher forwards it by name to the worker's kudo MCP
and hooks, alongside `KUDO_CONTEXT_MIRROR`, `AWS_ENDPOINT` and `AWS_REGION`.
It does not set `HTTP_PROXY` or `HTTPS_PROXY`, and it changes no networking
outside the mirror's S3 client. Existing AWS credentials continue to reach
workers only by inheritance, never through command-line configuration.

**Chosen.** Preserve OneCLI and each agent's existing network policy while
allowing context synchronization to use a reachable host proxy.

**Rejected.** Setting a process-wide proxy on `kudo-node`, which would also
reroute worker and agent traffic.

**Escape hatch.** Leave the variable unset for direct mirror access.
