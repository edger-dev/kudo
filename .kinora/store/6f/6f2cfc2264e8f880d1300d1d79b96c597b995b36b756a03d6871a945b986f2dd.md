# Spec — a context is the unit of memory, and it names the repos it spans

**Contract.** The thing a worker is bound to, and the thing a human opens in
kudo, is a **context**: a kino in a kinora store that holds, for one piece of
work,

- a **resume block**, the context's head, kept short (a screen or less) and
  never edited: each submission supersedes it with a new version, and the
  supersedes chain is its history:
  *where* it stands with the verdict first, the *next* action and who takes it,
  what is *established* with a pointer to its evidence, and what is still
  *open*;
- its **log**, which is the submissions written under it (found by backlink,
  each citing its evidence), not a section of the context;
- the **repos** the work spans, by path on a named node, so a worker can be
  started in any of them under the same context; the declaration doubles as
  the mounts table — naming a repo names its ledger;
- its **queue**: the items enqueued under it, pulled by workers.

A context is not a session, not a repo, and not a workflow run. A worker
started under a context reads its resume block first and submits back into it;
a human reads the same block to pick the work up cold.

**Chosen.** The resume-block-plus-log shape, lifted out of the notes vault
where it was trialled for two weeks on real cases and passed. Multi-repo by
declaration, because the working directory stopped identifying the work the
moment the work crossed repos — the cwd became "the desk", carrying no case
identity.

**Rejected.** A context per repo (the cwd-as-identity model the agent CLI
defaults to): it fragments one piece of work across as many memories as it has
repos. Also rejected: keeping the memory in the transcript history and resuming
sessions — half of all sessions got resumed in the measured period, each with a
cold cache, and the busiest cases still spanned eight sessions.

**Escape hatch.** A context may point at a longer hand-over document when its
log outgrows a skim; the resume block links it, and a worker reads it only when
the block says to.
