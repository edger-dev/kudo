# Spec — a completed worker session leaves a raw transcript and a deterministic distillation

**Contract.** At SessionEnd, the agent harness files the session's raw JSONL transcript as a content-addressed record in the context store, linked to its context and lease. It then writes a separate distilled kino with `derived-from` naming the raw record: one turn per line with `{line, speaker, kind, text, ts}`; line numbers are the span-address space. Distillation is deterministic code, not an agent. Both records sync through the deployment's existing private-by-tenancy mirror so a console on a second node can read them.

Only a completed session is distilled. There are no incremental distilled versions, and an earlier submission never cites a transcript version that did not exist when it submitted; its existing tool, job, kino, and URL evidence remains valid. Raw and distilled records stay separate so mechanical session content and line-addressed evidence cannot drift together.

**Chosen.** SessionEnd is the one automatic capture point already inside the worker lifecycle; it needs no watcher and never leaves a growing transcript's line map unsettled. The existing mirror is the note's intended phase-3 object path.

**Rejected.** Continuous watchers, manual filing, raw-only storage without line addressing, and incremental distillation at each submit. Shared workplace mirrors without the required encryption boundary are not made safe by this contract.

**Escape hatch.** A harness whose CLI exposes no completed transcript path records the gap rather than inventing content. Incremental distillation can become a later spec if live span evidence proves necessary.
