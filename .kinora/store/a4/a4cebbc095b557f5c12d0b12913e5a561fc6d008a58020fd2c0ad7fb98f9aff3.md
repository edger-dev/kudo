# Spec — Start implementation from an intake note

**Contract.** The console lists remote intake notes with title, body, author,
machine, session, and received time. A Start implementation action creates one
context containing the note's design and kino id, declares a permitted wake
node, and enqueues an ask to decompose and execute the design in small serial
steps. The note is linked to the context but not converted into a spec or
marked reviewed. Existing context head and trace views show progress.

**Why.** The intended workflow is design agent to Kinora inbox to small worker
steps. Reusing the context engine and wake scheduler avoids a second messaging
system, a worker pool, and manual worker launch.

**Rejected.** Automatic spec generation, daemon workers, worktree/PR workflow,
mandatory per-step design approval, or a new intake transport.

**Escape hatch.** Later task graphs, explicit parallel policies, worktrees, and
pull requests can build on the same note-to-context link.
