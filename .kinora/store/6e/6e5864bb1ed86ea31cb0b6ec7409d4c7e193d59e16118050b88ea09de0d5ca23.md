# Decision, 21 Oct 2026: two hosts federate as peer hubs

Designed from the finding kino://6e1eec36b63e452fb7348982a9cd8b64f66dcd45097488d9098c4f2c25337b08 (author, by tap):

- **Peer hubs**, one hop: each host keeps its own hub; hubs dial a static
  list of named peers (`HUB_NAME`, `HUB_PEERS`) and exchange registries.
- **Names:** a peer's nodes appear as `edger::yolo`; local names stay bare;
  `::` is reserved.
- **Events** cross only while someone on the other side subscribes.
- **Trust:** the private network only, for now (open: peer auth).
