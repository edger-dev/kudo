# Spec — an established line needs evidence that resolves, or it is claimed

**Contract.** A submission is one typed input: what the worker
**established** (each line with its evidence), what it only **claims**, what
it **ruled out** and why, the **gaps** it could not see, and the full new
head. The submit tool checks every evidence entry on an established line:

- a **kino id** (bare, or as a `kino://` link) must resolve to a kino that
  can back a fact: one in the ledger of a repo the context declares — copied
  into the context store with its origin named (cite-and-cache), so the
  context reads whole without the repo — or an earlier submission. The
  queue's own records (the context, its heads, items, claims, settlements,
  the repos declaration, inbox lines) back nothing, and citing them does not
  count;
- a **recorded tool call** of the context — a shell call or a governed job's
  start or end, written into a lease's trace by the hook as it returned
  (kino://6061a14e7f9b9eb2c7a3bbc0f5ff4f3778ceb08d71d46f8de4515f62ef3a2a0b) — counts: it is the loop's own record of what ran and what
  it printed;
- a **transcript span** `transcript:<distilled-id>:<first>-<last>` resolves
  when that distilled record belongs to this context and the inclusive line
  range exists. Raw transcripts and spans in another context back nothing.
  Completed-session capture is specified by
  kino://0139122baa08b2f39720a8b6fb15e848c96ca7fb8ccdd6056ae9e2287e0397ea;
- a **URL** (`http://` or `https://`, with a host, no whitespace) is accepted
  as given.

An established line with no evidence that passes is **moved to claimed**, not
refused: the submission lands, and reads as what it is. The submission's body
is rendered from the input in fixed sections (Established / Claimed / Ruled
out / Gaps), so it reads cold; free text cannot forge a section (list items
stay on one line, a log line that reads as a heading is escaped).

**Chosen.** Enforcement in the tool, by downgrade. The orchestrator's harness
proved that an unchecked "established" drifts into confident prose; refusing
outright makes a worker invent citations to get through. Downgrading keeps the
honest submission and makes the claim visible as a claim. Transcript spans are
accepted only after SessionEnd has filed the distilled record.

**Rejected.** Kino ids only (a worker would file a kino for every test run it
cites). Any non-empty evidence (citations stop meaning anything). Parsing the
markdown head for evidence (parse drift; the typed input is the contract).
Accepting a span without checking its distilled record and line range.

**Escape hatch.** A new evidence form (a moco blob hash) is one more resolver
behind the same check; until it exists, its lines are claimed, never lost.
