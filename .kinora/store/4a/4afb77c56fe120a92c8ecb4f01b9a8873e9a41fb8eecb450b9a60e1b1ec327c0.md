# Spec — a context declares the node its woken workers start on

**Contract.** A context may declare a **wake node** (`kudo-shim context
wake-node <ctx> <node>`), written as its own kino; the latest declaration
wins. Without one, a woken worker starts on the node of the context's first
declared repo, else on the waker's own node.

**Chosen.** Where a context's work runs is the context's to say, as its repos
are; the default follows the repos, so most contexts need nothing.

**Rejected.** Always the waker's node (a context whose repos live elsewhere
would wake where its work is not).

**Escape hatch.** The worker reaches any other node through governed jobs.
